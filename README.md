# 🤖 Gemini ChatBot – Powered by Google AI

Um chatbot simples, leve e funcional em Python que utiliza a **API Gemini (Google Generative Language)** para gerar respostas inteligentes em tempo real. Ideal para estudos, protótipos, automações e aprendizado de IA.

## 🧠 O que ele faz?

- Envia perguntas para a API do Gemini 2.0 Flash
- Recebe respostas diretamente do modelo de linguagem da Google
- Executa tudo em tempo real no terminal
- Leve, fácil de personalizar e expandir
- Rodando liso no **Termux**, Linux, ou qualquer ambiente com Python
